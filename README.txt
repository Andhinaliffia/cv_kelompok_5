THREEFOLIO — WEBSITE CV 3 ORANG

Isi folder:
- index.html : halaman utama berisi tiga kartu profil dan CV lengkap
- style.css  : tampilan, warna, animasi hover, dan layout responsif
- images/    : foto masing-masing profil

Cara pakai:
1. Ekstrak ZIP.
2. Pastikan index.html, style.css, dan folder images tetap berada di lokasi yang sama.
3. Buka index.html di browser untuk preview.
4. Untuk mengunggah ke GitHub Pages: buat repository, upload semua isi folder ini (bukan file ZIP-nya saja), lalu buka Settings > Pages dan pilih branch main / root.
5. Setelah GitHub Pages aktif, website dapat dibuka melalui satu link.

Catatan:
- Kontak dan pengalaman ditampilkan sesuai materi CV yang diunggah.
- Semua foto berasal dari tiga foto yang dikirim bersama CV.
